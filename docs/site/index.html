下载与安装

v0.0.8 · 2026.10.21
macOS 安装说明macOS 14+ · 通用架构

推荐通过 Homebrew 安装，Apple Silicon 与 Intel 均可使用。

brew install --cask crazykun/ailater/latermd

也可以下载 DMG 并拖入「应用程序」。本项目未做代码签名与公证，首次打开可能被系统阻止。请先确认安装包来自本项目 Release，再参考官方安装说明处理；不要关闭系统的全局安全保护。

查看官方安装说明
Windows 安装说明Windows 11+ · x64

下载 .exe 安装器并按向导安装，也可以使用免安装版本。当前不支持 Windows 10。由于应用未签名，SmartScreen 可能提示风险；请确认来源可信后，按项目说明操作。

下载 ZIP 便携版 下载独立 EXE
Linux 安装说明x64 · X11 / Wayland

Debian / Ubuntu 可使用 .deb 安装包。其他发行版可下载 tar.xz 归档，解压后运行 ./latermd。需要可用的图形环境与相应运行依赖。
