# 写作、源码与分栏（三态视图）

## 关系

| 入口 | 用途 | 可编辑 | 渲染什么 |
|---|---|---|---|
| 写作 | 直接在正文中写，当前段落显示 Markdown，其余段落渲染排版 | 是 | Live 块级富渲染 |
| 源码 | 检查和编辑完整 Markdown 标记 | 是 | 不渲染 |
| 分栏 | 源码（左）+ 只读对照（右） | 左可编辑、右**只读** | 右栏渲染的是**同一份文档的 Live 富渲染**，不是第二套渲染器 |

标题栏三段开关「写作｜源码｜分栏」与 `Ctrl/Cmd+/` 共用同一个入口（命令 `ToggleLivePreview`），归约按
`RenderMode::cycle()` 推进 `源码 → 写作 → 分栏 → 源码`。三段是循环的：点任一未选中的段只推进一档，
点到目标档需要连点（与点开关的语义一致）。

三档**互斥**，分栏是第三档本身，不是「源码 + 一个可独立开关的面板」。右栏的开合就是 `render_mode`，
不存在额外的开关 bool，也不再有「离开写作时右栏该不该回来」那类快照补工。

写作仍为按块编辑，不承诺完全所见即所得（True WYSIWYG 是 non-goals，见 AGENTS.md §7）。

## 切换与恢复

- 无模式记录时（新安装）进入写作档。
- `render_mode` 随布局一起持久化；旧存档只有 source / live 两档，split 是新值，走同一条装载路径
  按循环推进到位，**无需新增迁移**。
- 主动选择的档位在下次启动恢复。
- 切档时**先退出禅定**再切，避免禅定布局被写模式借用。
- 点已选中的段无操作。切档不修改文档、不清空选区或重建编辑缓冲。
- 源码 ⇄ 写作之间交接插入点：离开写作档把最后的活动插入点写回源码 TextEdit；从源码切入写作保留
  插入点并交给对应 Live 块。分栏的中央仍是源码 TextEdit（与源码档同一 widget id），光标无需交接。
- 分栏右栏的只读是**每帧置位的 UI 侧硬锁**（`browse_only` + `!browse_enabled` + `browse_locked`），
  点击/双击/跳转都不进编辑、不抢焦点，**不写回 State**（同禅定浏览态的手法）。
- 右栏**跟随一次**：源码侧光标移动才下滚动目标，落到目标的帧消费后即清；此后右栏保留自己的滚动
  位置供自由翻阅。
- 右栏开合的**进场动画按来源分两条通道**（2026-10-19 坤哥两轮）：
  - **写作 → 分栏**：列整块盖在编辑区上，由左向右推进到槽位（第一轮：
    「切换分栏的时候改成窗口向右滑动，而不是现在的从边上进来」）。
  - **源码 → 分栏**：保留 egui 原生观感，列仍在屏幕右缘外向左进（第二轮：
    「源码模式从右往左，是之前的模式」）。
  - **退场**（任何档 → 非分栏）：走 egui 原生滑出（第一轮明确「退场不动」）。

  两条进场通道的**起点视觉完全一样**（编辑区都是满宽的源码 TextEdit），
  单看当前 `render_mode` 分不出来，故来源由归约记在 `State::split_enter_from`
  （只在 `set_render_mode` 的进场分支写一次）。冷启动恢复到分栏档时该字段
  取初值 `Source`，即走旧观感 —— 「向右滑」表达的是「你刚从写作档切过来」，
  启动恢复并没有「上一档」这回事。

  向右滑那条必须绕开 egui 的收展通道：它的实现是把面板**向固定边（右缘）
  平移**并按可见部分裁剪（`panel.rs` 的 `slide_distance` /
  `visible_outer_rect`），**只可能**得到「从屏幕右缘飞进来」。绕法是自己驱动
  一条独立动画 `enter-slide`，并在进场期间把 egui 的收展比例**钉死在展开
  端点**：槽位当帧到位（编辑区立刻收窄），位移与正文绘制另走一路（`draw`
  的 ⑤'，中央编辑区之后，clip 自给）。三条路径按 `slide_right` 互斥，任一
  帧只画一次；正文内一切 widget 的 id 由 `COMPARE_BODY_ID` 钉死，进退场、
  两条进场通道来回切都不丢滚动位置。
  **拖到最小宽再往外拖**（drag-to-collapse）或双击分隔线会收起右栏并切回
  源码档；完全收起后右缘留一根细把手，往外拖可重新展开为分栏档
  （写作 / 源码档也在）。`render_mode` 是唯一状态源：egui 翻转的工作 bool
  经 `CompareColumnToggled` 收敛回档位。
- 右栏顶部有**列头**（`pane_heading`：左侧「对照」、右缘「只读」徽标），
  固定在滚动区外。三态下右栏身份是「Live 富渲染的只读对照」，不再叫旧
  「对照预览」。
- 右栏在审阅 Git diff 工作区时让位（与旧对照预览口径一致）。
- 禅定保留现有沉浸阅读语义：正文是 Live 富渲染的只读浏览态，点大纲只滚动不进编辑。重启不恢复
  临时禅定态。
- 保存布局时不把禅定临时隐藏的面板偏好覆盖成永久选择。

两种编辑档（写作 / 源码）沿用现有 buffer 和撤销行为；写作的撤销仍按活动块分段。内部命令 ID 只有
`ToggleLivePreview`（id `toggle_live_preview`）一条；旧的 `ToggleRightPreview` 已随右栏独立开关一并
删除，keymap.json 里残留的 `toggle_right_preview` 键是多余条目（按 Command id 查询永远查不到），无
副作用。

## 验证范围

覆盖首次启动、旧 JSON 迁移、三档重启往返、禅定交互、文本/修订号不变、档位点击路由及文字中心线。
实际窗口检查写作、源码、分栏和窄窗；Windows/Linux 原生外观仍需真机复核。
