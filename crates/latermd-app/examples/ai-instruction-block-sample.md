# ```ai 指令块冒烟样例

用 LaterMD 打开本文件(文件 → 打开),写作模式里 ```ai 围栏渲染为**指令卡**
(分栏档下右侧的只读对照列同样渲染):
卡片显示指令文本 + 状态行(未执行/进行中/已完成)+「执行」按钮。

## 点击「执行」→ Mock 流式续写

```ai
续写一段 Markdown 介绍
```

点击后 AI 文本流式追加到本文档末尾;状态行随 `AiState` 变化:
流式进行中显示「进行中…」,成功收尾后显示「已完成」,失败回到「未执行」
(错误原因见状态栏提示行)。与 [ai:// 链接](ai://write?prompt=%E7%BB%AD%E5%86%99) 走
同一条消息与归约,流式进行中再点任何入口都会被防重入忽略。

## 不受影响:其它围栏照常渲染

```rust

    println!("只有首词是 ai 的 info string 才是指令卡");
```

大小写敏感。协议与状态语义见 docs/decisions-pending.md #12/#13。
